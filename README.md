# REMATCH Major League

REMATCH Major League (RML) is a developmental esports league for REMATCH. Led by the President of RML, Moose, RML has strived to be a spearhead in the launch of REMATCH esports, and in doing so, has become the main starting spot for teams to start their career. With the help of the community, as well as the staff of RML, the league is a constantly evolving place, always making sure to provide a well-suited place for teams to flourish.

This Github Page is for the programming of all RML-related tasks, namely:

* RML API
* RML Discord Bot
* RML Website

This will also house any other further projects for RML, as seen fit for the progression of the league, as well as the game itself.
